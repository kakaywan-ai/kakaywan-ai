# Documentation

This is a public repository. Store only documentation and evidence that the team is authorized to publish.

| Location | What belongs here |
|---|---|
| `docs/ARCHITECTURE.md` | System architecture and component diagram |
| `docs/API_CONTRACT.md` | Frontend/backend request and response agreement |
| `docs/setup/` | Public setup instructions, verified links, starter issues |
| `docs/` | Technical notes, evaluation methodology, sanitized project documentation |

Do not store original CEPMO documents, letters, signed approvals, private correspondence, internal meeting notes, or unapproved photos here. Keep them in restricted team storage. The proposal and CEPMO request letter were intentionally excluded from this public starter package.
